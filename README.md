📊 Retail Sales Data Analysis

End-to-End Data Analyst Portfolio Project

A complete Retail Sales Data Analysis project using Excel, SQL, Python, and Power BI to analyze sales performance, profitability, customer purchasing patterns, and business trends.

---

🎯 Project Objective

The main objective of this project is to analyze retail sales data and generate meaningful business insights that can help organizations make better data-driven decisions.

🛠️ Tools & Technologies

- Microsoft Excel: Data Cleaning, Pivot Tables, Data Analysis
- SQL: Data Querying, Aggregation, Business Analysis
- Python: Pandas, NumPy, Matplotlib
- Power BI: Interactive Dashboard, DAX Measures, Data Visualization

📁 Dataset Information

- Total Records: 1,200
- Total Columns: 14
- Dataset Type: Synthetic Retail Sales Dataset
- Time Period: January–December 2025
- Cities: 8
- Product Categories: 5

Dataset Columns

Order_ID, Order_Date, Customer_ID, City, Category, Product, Quantity, Unit_Price, Discount_Rate, Revenue, Cost, Profit, Payment_Method, Order_Status.

💡 Key Business Insights

- Electronics is the highest revenue-generating category.
- Kolkata has the highest revenue among the eight cities.
- May 2025 recorded the highest monthly revenue.
- Power Bank generated the highest product-level profit.
- UPI is the most frequently used payment method.
- Overall profit margin is approximately 27.78%.
